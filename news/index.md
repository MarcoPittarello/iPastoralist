# Changelog

## iPastoralist 2.3.3

### New features

- Added support for modified TWINSPAN classification.
- Introduced new functions for TWINSPAN visualization and
  interpretation.
- Added tools for optimizing hierarchical clustering.
- Introduced synoptic tables for phytosociological analysis.
- Added transformation-based PCA visualization.
- Improved documentation and tutorials.

### Maintenance

- Updated package dependencies.
